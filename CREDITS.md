# Credits and project history

This repository is a maintained fork of
[nathanvdh/homeassistant-airtouch2plus](https://github.com/nathanvdh/homeassistant-airtouch2plus).

The original Home Assistant integration and the supporting
[airtouch2-python](https://github.com/nathanvdh/airtouch2-python) library were
created by Nathan van der Heijden (`@nathanvdh`). The existing contributors and
Git history remain the authoritative record of earlier work.

This fork is maintained by Kip Duggin (`@honeybadger44`) to improve reliability
and investigate additional local AirTouch 2+ functions, including native
external-temperature reporting.

AirTouch and Polyaire are trademarks of their respective owners. This is an
independent community project and is not affiliated with or endorsed by
Polyaire.

No licence file was present in the upstream repository when this fork was
prepared. No additional licence is asserted by this housekeeping change.
